## ✨ Features

- 🧾 Quick & easy billing
- 📦 Inventory management
- 📊 Sales tracking & reports
- 🧮 Automatic total & tax calculations

## 🛠️ Built With

- **JavaScript — business logic**
- **HTML/CSS — touch-friendly UI**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Keshab1997/smart-pos-app.git
# Install dependencies
npm install
# Start the app
npm run dev
```

🔗 **Try it live:** [https://smart-pos-app-sepia.vercel.app](https://smart-pos-app-sepia.vercel.app)
